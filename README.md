# Mesa dos Reis

Ranking comunitário de builds de 9 Kings. Site estático (GitHub Pages) com login, builds e votos no Supabase.

- `index.html`: o site
- `config.js`: URL e chave pública (anon) do Supabase
- `supabase.js`: biblioteca supabase-js 2.117.1 (UMD)
- `supabase/schema.sql`: tabelas, regras de acesso e builds de exemplo
